# Sports-Lexical-Ambiguity 
Final Project Proposal Ling 230: Public-Facing Artifact + Rational Essay
For my project I am planning on doing Option 2. When we were first talking about lexical
ambiguity in the earlier part of the semester I immediately thought about how it applies in sports
discourse. I began to work on the framework and coding portions as a side project to add to my
github portfolio, but I was not able to put enough time to the side and stopped working on it.
The idea I first had was to make a code that would act as a lexical ambiguity or machine
translator to translate what the user inputted and it would output what the actual meaning about
it was based on certain verbiage or phrasings used. It would use the urban dictionary definitions
because those have a lot of slang terminology that is used throughout social media. This was
my initial idea, but expanding on this I want to compare and analyze the socioelect communities
of ‘Sports Twitter’. I am a part of these but more specifically NBA twitter, NFL twitter, and
Soccer/Futbol twitter. These are the three sociolect communities that I will be focusing on for the
project because a lot of the members, a part of them, are directly tied and connected with each
community.
The project's core idea and framework is developing an interactive website that analyzes
and examines how soccer, NFL, and NBA twitter communities create unique sociolects.
Everyday words such as “cook”, “sell”, “fried” display meanings that apply to specific
communities and groups. These meanings depend heavily on context, but also who is speaking
and the intended target audience. In the end it will pair the website along with the rationale
essay and final presentation.
Intended Audience
The primary audience are sports fans and enthusiasts, those that actively use social
media and especially those that are in these sociolects or are new to them. Another audience
that fits are Computer Science and Lings majors and those interested or already in the NLP
field. Perfect circumstances would be those that share the two descriptions. As a secondary
audience, because this will be added to my github and hosted through its pages. Those that
come across my account can view the repo and see the site in action. Since I plan on adding
this project to my resume, it can also be intended for recruiters and or hiring managers. With this
being said, the audience should learn how slang words are able to take on specific meanings in
these sociolects. They can see how the meaning of a word is able to have different senses. As
far as understanding sport’s fan talk or narratives ,they aren’t just using random words or
phrasings. The three communities have their own structured language that can be understood
by others because of shared contexts.
Creating an interactive website fits because it allows people to easily interact with each
component and test it out themselves to see. They can paste their own tweets into and see how
it gives a different meaning. Having it hosted through GitHub pages is well suited because they
offer a free host service and people are able to see the contents of the files and code needed for
the website to function properly

Website Development/Initial Planning of Project
The site will be developed based on two components. The first component that will be
developed is a decoder that will translate standard meanings to the actual meanings seen in
these three communities. It will also let users compare and identify patterns that are seen
across each community. The second component is developing an interactive playground where
users or visitors can enter their own sports tweet examples to see how NLP tools can
misclassify or misinterpret them. LLM’s are modern and highly advanced NLP tools that can do
this, but traditional and standard NLP tools have issues with it. This identifies and displays a
slight issue or problem that's why as a solution I am going to create a specialized NLP tool like a
bot that focuses on the sports discourse of these three sociolect groups.
There are a variety of concepts and frameworks that apply to developing this project.
When it comes to semantics and morphology, understanding lexical ambiguity and
morphological blends are going to be key details to remember. For pragmatics and discourse, I
expect for there to be lots of presupposition, in-group signaling and the speech act framework.
As far as computational frameworking it will evaluate some of the algorithmic biases that NLP
tools can have when processing the jargon, vernacular, and in-group signaling in these specific
sociolects.
